 📖 About the Project

**SNACCY** is a responsive front-end food delivery web application inspired by platforms like Swiggy and Zomato. Users can pick their city, browse food categories, explore popular restaurants, view menus, add items to the cart, and get food suggestions based on their mood.

This project was built to practice front-end web development: UI design, multi-page navigation, and interactive features using HTML, CSS and JavaScript.

 ✨ Features

- 📍 **City selection** – Ahmedabad, Bangalore, Hyderabad, Mumbai, Delhi, Kolkata, Pune, Chennai, Jaipur, or All India
- 🍕 **"What's on your mind?" slider** – scrollable food categories (Homely Food, Cake, Samosa, Pizza, Burger, Idli, Juice, Dosa, Momos, Noodles, Pasta, Salad, Roll, Shawarma)
- 🏪 **Restaurants with online delivery** – KFC, Pizza Hut, Domino's, Biryani House, Burger King, La Pino'z Pizza, Live Cake, Starbucks
- ⭐ **Ratings and delivery time** shown on every restaurant card
- 📋 **Individual restaurant menu pages**
- 🛒 **Cart page** to manage selected items
- 🤖 **AI Food Recommendation** – tell SNACCY your mood and get a food suggestion
- 🔔 **Notifications panel** with a live counter
- ✨ **Offers page** for deals and discounts
- ☎ **Help page** for customer support
- 💻 **Sign Up page** for new users
- 🌆 **Cities with food delivery** section featuring famous landmarks
- 📱 **Responsive design** for desktop, tablet and mobile

🚀 Getting Started

# Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dhavalrathod1537/SNACCY_Food_delivery-web.git
   ```

2. **Go to the project folder**
   ```bash
   cd SNACCY_Food_delivery-web
   ```

3. **Open the project**
   - Double-click `index.html`, **or**
   - Use the *Live Server* extension in VS Code for auto-reload.

No installation or build step is needed. It's a pure front-end project.

### Deploy on GitHub Pages

1. Push the code to your GitHub repository.
2. Go to **Settings → Pages**.
3. Under *Source*, select the `main` branch and `/ (root)` folder.
4. Save. Your site will be live at `https://<username>.github.io/SNACCY_Food_delivery-web/`.
